Ethical Agent

Roda um dataset rotulado contra a engine e reporta métricas. Não grava na trilha de auditoria. Datasets grandes podem demorar.

Vale só para esta execução. Comparar as três pode levar tempo.

O que são tune e holdout?

Os datasets externos são partidos ao meio por um hash do id de cada caso (receita divisao/v1), e a metade que você escolhe depende do que quer descobrir.

  • Tune — Metade de treino, contra a qual se pode ajustar regras e léxico. Como as regras foram ajustadas olhando para esses casos, o resultado aqui é sempre melhor do que o real. Útil para quando estiver corrigindo uma regra e quiser verificar se a correção funcionou.
  • Holdout — A metade que ficou de fora do ajuste. Ela que mostra como o sistema se sai diante de casos novos. Use quando quiser saber o desempenho real do sistema.
  • Tune e Holdout, separadas — Use quando quiser comparar as duas. A diferença entre elas mostra o quanto o sistema depende dos casos que já viu. São o dataset inteiro.

Recall: É comparado entre metades. Diferentemente da proporção DENY/ALLOW, acurácia e F1 mudam, o recall não muda entre metades. Cada caixa repete o aviso com o número medido.
